# مجموعة بيانات ThreadGuard X العربية

## المصدر والشروط
- جميع العينات المرفقة في `train/` و `validation/` و `test/` هي **بيانات اصطناعية (Synthetic)** أُنشئت خصيصاً لاختبار محركات التحليل والوقاية من الإنذارات الكاذبة.
- لا تنسب أي عينة إلى مستخدم حقيقي أو تغريدة منشورة فعلياً على منصة X.
- جميع العينات موسومة صراحةً بالحقل `"is_synthetic": true`.

## الفصل بين المجموعات
- `train/`: لتطوير القواعد ومعايرة الفئات الأولية.
- `validation/`: لضبط حدود التشابه والكثافة وتقليل الإنذارات الكاذبة.
- `test/`: مجموعة اختبار مستقلة لا تُستخدم في ضبط القواعد وتُقاس عليها مؤشرات Precision و Recall و F1 و FPR و FNR.

## التصنيفات المعتمدة
- طبيعي
- سبام
- تكرار
- تسويق مزعج
- رابط مشبوه
- يحتاج مراجعة
- مؤشر مخالفة محتمل
- مشكلة في جودة الثريد
