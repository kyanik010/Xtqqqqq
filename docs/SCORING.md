# منهجية التقييم وإزالة التكرار (`SCORING.md`)

## منع احتساب الدليل مرتين
يستخدم كل دليل معرّف `dedupKey` موحداً عبر المحركات (مثل `CROSS_TWEET_SIMILARITY:0:1` أو `OBFUSCATION:0:اشتراك`).
يقوم `RiskEvidenceAggregator.deduplicateFindings()` بتجميع الأدلة حسب `dedupKey` والاحتفاظ بأعلى درجة خطورة/ثقة مرة واحدة فقط قبل الحساب.

## فصل مؤشر الخطورة عن درجة الثقة
- **مؤشر الخطورة (`riskScore`: 0–100)**: مجموع نقاط الأدلة غير المكررة:
  - منخفض (`LOW`): 6 نقاط
  - متوسط (`MEDIUM`): 16 نقطة
  - مرتفع (`HIGH`): 28 نقطة
  - حرج (`CRITICAL`): 45 نقطة
- **درجة الثقة (`confidenceScore`: 0%–98%)**: تُحسب بشكل مستقل من:
  - متوسط ثقة المحركات المكتملة (60%)
  - نسبة تغطية المحركات دون أعطال تقنية (25%)
  - كفاية طول العينة النصية (15%)

## قيود المنهجية
الأرقام والنقاط هي تصنيفات إرشادية أولية موثقة وقابلة للاختبار، وليست احتمالات إحصائية معايرة لحجب أو انتشار المنشورات على منصة X.
