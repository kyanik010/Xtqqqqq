# الخصوصية (`PRIVACY.md`)

- **لا حساب مطلوب**: يعمل التطبيق كاملاً دون تسجيل دخول.
- **عدم التخزين الافتراضي**: تبقى نصوص التغريدات في ذاكرة الجلسة المؤقتة فقط، وتم تعطيل النسخ الاحتياطي التلقائي للنظام (`android:allowBackup="false"`).
- **عدم التسجيل في السجلات**: لا تُطبع نصوص المستخدمين في سجلات الأخطاء.
- **محلي أولاً**: تعمل جميع المحركات الستة محلياً دون إرسال النصوص لأي خادم أو نموذج ذكاء اصطناعي خارجي.
- **الفحص المباشر للروابط اختياري**: معطّل افتراضياً؛ وعند تفعيله يرسل طلب `HEAD` للرابط نفسه فقط عبر `SsrfUrlGuard` دون إرسال محتوى التغريدة.
