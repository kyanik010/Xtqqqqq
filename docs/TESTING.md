# الاختبارات وضمان الجودة (`TESTING.md`)

## مجموعات الاختبار المنفذة
- **اختبارات محرك اللغة العربية**: التطبيع، الهمزات، التشكيل، التطويل، اللهجات، الكلمات المختلطة، الحروف المكررة، التمويه، التشابه الدلالي.
- **اختبارات محرك السبام والسياق**: التكرار الكامل والجزئي والدلالي، الروابط المكررة، الترويج المزعج، وحالات IPTV العشر لضمان التمييز بين الشرح التقني والسبام.
- **اختبارات محرك السياسات**: منع الإنذار الكاذب من كلمة مفردة، التمييز بين التحذير والاقتباس والنقد والمخالفة المحتملة.
- **اختبارات الأمان وSSRF**: حظر `localhost` و`127.0.0.1` و`10.0.0.1` و`192.168.1.1` و`169.254.169.254` و`::1` و`::ffff:127.0.0.1` والتحويل الخبيث نحو IP داخلي.
- **اختبارات جودة الثريد والتجميع**: منع احتساب الدليل مرتين، عزل أعطال المحركات، الحدود القابلة للتغيير.
- **اختبارات القياس الكمي على مجموعة اختبار مستقلة (`datasets/test/synthetic_test.json`)**: حساب Precision و Recall و F1 و FPR و FNR.
- **اختبارات واجهة Robolectric**: التحقق من الواجهة العربية RTL، تحرير الثريد، الفحص الشامل، الانتقال للتحذير، ومقارنة/قبول/استعادة اقتراحات التحسين.
