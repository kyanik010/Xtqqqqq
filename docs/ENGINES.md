# شرح المحركات وكيفية التوسعة

## 1. محرك اللغة العربية (`ArabicTextIntelligenceEngine`)
- ينفذ التطبيع داخلياً فقط (حذف التشكيل والتطويل وتوحيد أشكال الألف والأرقام والمحارف البديلة) مع **إبقاء النص الأصلي للمستخدم كما هو**. يحافظ على الفروق المعنوية في (ة/ه) و(ؤ/و) و(ئ/ي).
- يكتشف: اللهجات، الخلط العربي/الإنجليزي، فصل الأحرف (`ا ش ت ر ا ك`)، التداخل بالرموز (`ا.ش.ت.ر.ا.ك`)، التمديد المفرط (`مجاااااني`)، والأحرف الخفية.
- يحسب **التشابه النصي/اللفظي** بمطابقة الرموز والجذور التقريبية وتشابه المحارف. هذا ليس فهماً دلالياً ولا يكتشف تكافؤ المعنى بين صياغتين مختلفتين؛ يتطلب ذلك نموذج تضمين جمل عربي مدرّباً ومقيّماً قبل تفعيله.

## 2. محرك اكتشاف السبام (`SpamDetectionEngine`)
- يفصل السياق (`TECHNICAL_EXPLANATION`, `EDUCATIONAL`, `NORMAL_COMMERCIAL`, `PROMOTIONAL_SPAM`, `REPETITIVE_MARKETING`, `EVASION_ATTEMPT`).
- لا يصنف مجرد وجود كلمات تقنية مثل `IPTV` أو `سيرفر` أو `اشتراك` أو `مشغل` كسبام عند ورودها في سياق شرح أو مقارنة تقنية.

## 3. محرك سياسات المحتوى (`PolicyRiskEngine`)
- يمتلك فئات قابلة للتوسعة عبر `PolicyCategoryRule`.
- يمنع الإنذار من كلمة منفردة؛ يتطلب عبارة مركبة أو مؤشرين متساندين، ويخفف التصنيف عند رصد إطار تحذيري أو تعليمي أو اقتباس.

## 4. محرك تحليل الروابط (`UrlIntelligenceEngine`)
- يستخرج الروابط، ويميز الروابط المختصرة، وعناوين IP المباشرة، والنطاقات المتشابهة (Levenshtein)، ومؤشرات التصيد.
- إذا تعذر الفحص أو كان معطلاً يعرض الحالة `غير مفحوص` صراحةً. يستخدم فاحص التحويلات محلل DNS يتحقق من كل عنوان عند لحظة الاتصال ويمرر عناوين IP نفسها إلى OkHttp لمنع إعادة حل DNS غير الموثوقة.

## 5. محرك جودة الثريد (`ThreadQualityEngine`)
- يفحص طول كل تغريدة مقارنة بالحد القابل للتعديل، وتكرار الأفكار، والتناقض المحتمل، والمقدمة والخاتمة، وتحديد رقم التغريدة المسببة للملاحظة.

## 6. محرك تقييم مخاطر الظهور (`VisibilityRiskEngine`)
- يجمع مؤشرات الاحتكاك المحتملة مع التزام صارم بعدم الادعاء بمعرفة خوارزمية X الداخلية.
